Salary calculator (date range)

Salary is calculated for the date range you choose (From → To). The From date auto-fills: to the last salary paid to that employee, or to the joining date if the employee is a new hire with no salary paid yet. Leave days in the range are cut automatically. Monthly employees: per-day pro-rata (monthly wage ÷ days in that month × duty days), summed across any months in the range — a full month with no leave equals full salary. Per-day employees: rate × duty days. For 24-hr duty employees a time option appears so days are counted by 24-hour shifts (e.g. 8 AM → 8 AM = 1 day).

Client billing calculator Mid-month deal

If a client starts or discontinues service in the middle of a month, pick the client and the service period (From → To). For each calendar month in the range the bill is deal amount ÷ days in that month × service days. Whatever the client already paid in that same month is subtracted from that month's bill, so each month shows its own balance; the balances are then totalled. The deal amount is the client's agreed monthly package — set it once in Money Entry and it is remembered here.

Monthly profit / loss — 50-50 partner share

Calculated by calendar month: Client money received − Employee payments − Other expenses. Profit or loss is divided equally between both partners.

Connect your Google account

Every submit is saved on this device instantly, and also sent to your Google Sheet in its own tab (Employees, DutyLeave, EmployeePayments, ClientReceipts, Expenses) once you sign in. No shared URL and nothing to host — you sign in with your own Google account and the app talks to the Sheet directly.
Google OAuth Client ID
Paste the Client ID (never the Client secret) from Google Cloud Console → APIs & Services → Credentials → OAuth 2.0 Client IDs, row of type Web application. Saving here fixes only this device and works instantly; put the same ID in config.js so every phone is pre-configured.
Google Sheet to write into
⚠ Hisab never creates a new Google Sheet — the Sheets API cannot make files, so signing in will not put a new file in your Drive. What it creates is the 5 tabs (Employees, DutyLeave, EmployeePayments, ClientReceipts, Expenses) inside the Sheet named here, and every entry goes into them. So the Sheet must already exist: press 🆕 New empty Sheet, then paste its address below.
Saving here fixes only this device and works instantly. Put the same ID in config.js as HISAB_SPREADSHEET_ID so every phone writes to the same Sheet — one shared Sheet for the whole team, each partner signed in with their own Google account.

Setup check for the admin

One-time setup (5 minutes, admin only)

  1. Open console.cloud.google.com → create (or pick) a project, e.g. Hisab.
  2. Menu APIs & Services → Library → search Google Sheets API → Enable.
  3. APIs & Services → OAuth consent screen → choose Internal (Google Workspace: only accounts in your organisation can sign in — this is the “Google Workspace OAuth” lock). If you don’t have Workspace, choose External and add your Google accounts as test users.
  4. APIs & Services → Credentials → Create credentials → OAuth client ID → type Web application.
  5. Under Authorised JavaScript origins add the exact address where the app is opened, e.g. https://ardashomehealthcare.github.io (add http://localhost:8000 too if you test locally). Sign-in only works from a listed origin.
  6. Copy the Client ID (the long address ending in .apps.googleusercontent.com — not the “Client secret”) and paste it in config.js as HISAB_GOOGLE_CLIENT_ID so every phone is ready. In a hurry, or the file value is wrong? Paste it in the Google OAuth Client ID box above and press 💾 Use this Client ID — that fixes this device at once, no re-upload needed.
  7. Press Sign in with Google → choose your work account → Allow. Done — every submit now goes straight from the browser to your Google Sheet. Each partner signs in with their own Google account (they need Editor access to the Sheet).
💡 The Sheet to write into comes from config.js (HISAB_SPREADSHEET_ID) — your existing sheet, so all existing data is kept, and it can be changed on any phone in the Google Sheet to write into box above without re-uploading anything. ⚠ Hisab never creates the Sheet file itself — Google’s Sheets API cannot make files. It creates the 5 tabs inside the Sheet you name, so create the Sheet once (🆕 New empty Sheet) and share it with every partner as Editor.
🩺 Press Check my Google setup above at any time: it shows the address Google must be told about, the Client ID in use and where it came from, whether the Sheet is reachable with your sign-in, and — if Google refused something — the exact clicks to fix it. Copy the report and send it to whoever manages your Google account.
⚠ Error 401: invalid_client while signing in means the Client ID itself is unknown to Google — it was typed with one wrong character, cut short, it is the Client secret, or that client / project was deleted. Nothing is broken in your data: make a new Web application client ID (steps 4–6) and paste it in the box above.
⚠ Error 403: access_denied is a different problem: Google did accept the Client ID and this web address, it refused the Google account. It means the OAuth consent screen is still in Testing and that address is not on the Test users list, or the screen is Internal and a personal @gmail.com was used. Fix it in APIs & Services → OAuth consent screen — Audience → Test users → + Add users for every partner, or Publish app — then press 🔐 Sign in with Google again. Pressing Cancel on the consent screen gives this same error, so choose Allow.
